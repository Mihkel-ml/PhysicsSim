# PhysicsSim  A lightweight 2D physics sandbox written in C++ using raylib. I built this project to learn how high school kinematics equations (like projectile motion, gravity, and drag) translate into step-by-step code algorithms.  The project uses modern C++ structure, keeping object declarations, physics definitions, and rendering loops cleanly separated across multiple files.  ## Features * **Explicit Graphing Trajectory:** A real-time, mathematically accurate dashed projection line that calculates future parabolic throwing arcs instantly using kinetic equations. * **Vector Visualizer:** A live debug arrow attached to the ball showing current velocity magnitude and direction. * **Real-time Telemetry HUD:** A custom dashboard overlay displaying live FPS, precise coordinate mapping, and velocity updates 60 times a second. * **Airtight 4-Wall Containment:** Bouncing logic with inelastic kinetic energy loss (damping) on impact across the floor, walls, and ceiling. * **Fluid Drag:** Simplified air resistance deceleration that naturally degrades horizontal momentum over time. * **Interactive Controls:** Left-click and drag the ball anywhere on the 1280x720 canvas to sling or throw it with simulated momentum.  ## Project Structure * `src/` - Pure source code files (main loop controller, Ball class header, and physics implementation). * `include/` - Third-party header dependencies (raylib blueprints). * `lib/` - Pre-compiled static binary architectures (`.a` files). * `build/` - Output directory for the compiled binary executable.  ## Controls * **Left Mouse Button:** Click and hold to grab the ball; drag and release to throw it.
